My Data Structures & Algorithms practice in **Python**, organised by topic. The code in every notebook is **exactly what I wrote while learning**; each notebook adds written explanations (idea, time/space complexity, key takeaways) and comments on top of it.

Where one of my cells had a bug, an unfinished idea or a stale output, a ⚠️ note explains it, so the notebook shows my real learning process.

## Patterns practised

- **Two pointers**: remove duplicates, move zeros, 3Sum / 4Sum, pair sum in a sorted DLL
- **Hashing**: Two Sum, longest consecutive sequence
- **Kadane / running best**: maximum subarray, stock profit
- **Binary search** on sorted and rotated arrays
- **Slow & fast pointers**: middle node, cycle detection
- **Pick / not-pick backtracking**: subsets, subsequences, combinations, N-Queens, Rat in a Maze
- **Stacks & queues**: valid parentheses, min stack, expression conversion, monotonic stack
- **Bit tricks**: XOR for the single number, bitmask for subsets
