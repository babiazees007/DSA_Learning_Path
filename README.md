# DSA Learning Path — Python

A structured, progressively harder collection of Data Structures & Algorithms problems solved in Python, practiced notebook by notebook. Each notebook comes with its own README explaining the problems, the pattern behind them, and the complexity trade-offs — not just the code.

**Goal:** build pattern-recognition for DSA problems from first principles (arrays, hashing, recursion) up through interview-standard topics (DP, trees, graphs).

---

## 📁 Repository Structure

Each folder = one practice session/topic. Every `.ipynb` has a matching `README.md` explaining what was practiced.

## 🧩 Topics Covered So Far

- **Digit manipulation** — extracting/rebuilding numbers digit by digit
- **Divisor-finding** — brute force vs. √n optimization
- **Hashing** — frequency dictionaries, direct-address tables, query-lookup optimization
- **Recursion fundamentals** — base cases, pre-order vs. post-order execution, accumulator-passing vs. return-value accumulation
- **Recursion on arrays/strings** — two-pointer recursion, palindrome checks
- **Branching recursion** — Fibonacci and the motivation for memoization

## 📌 How to Use This Repo

Each notebook README follows the same format:
1. **Problem table** — what was solved, grouped by concept
2. **Key idea** — the underlying pattern, not just the solution
3. **What's next** — how this topic connects to the next one in the path

The intent is to make this readable as a *learning trail*, not just a code dump — someone reviewing it (recruiter, interviewer, future me) should be able to see the reasoning progression, not just isolated snippets.

---

## 🎯 Why This Repo Exists

Built while preparing for AI/ML and Software Development roles as a fresher — DSA fluency is a core screening bar for both. This repo is the visible record of that practice, organized so the *progression* is the artifact, not just individual solved problems.
